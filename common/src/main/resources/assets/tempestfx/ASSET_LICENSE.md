# Asset provenance

All PNG and OGG files in this namespace, and the GLSL programs shipped under
`assets/minecraft/shaders`, are original work made for this project. They are
distributed under the repository MIT license.

Everything is synthesised from noise, filters, envelopes and drawn primitives.
No Minecraft, mod, shaderpack or web asset is read or sampled at any point, and
no recorded audio is used.

Textures are grayscale shape masks stored as white RGB with the mask in the
alpha channel; all colour is supplied by the renderer at draw time.
