# Thunderhead 1.0.0

Initial release for Minecraft 1.21.1.

### Lightning

- Huge procedurally generated lightning channels
- Dynamic branching with tapered trunks, forks and fine offshoots
- Multi-stroke flashes that revisit the channel
- Sky-spanning cloud branches and distant storm-front lightning
- Cold-white core with layered blue/violet glow

### Impact effects

- Ground shockwaves and bright impact bursts
- Sparks, micro-arcs, debris, dust, smoke, steam, ash and embers
- Water-specific spray, mist and surface ripples
- Electrical discharge effects on moving nearby entities
- Direct-hit ash imprints

### Atmosphere and audio

- Transient impact illumination and extended sky flashes
- Configurable screen flashes and camera pressure impulses
- Custom close cracks, heavy booms, distant rumbles and rolling thunder
- Distance-based thunder delay
- Rare ball-lightning events when installed on the server

### Performance and accessibility

- Low, Medium, High and Ultra quality presets
- Distance-based LOD, particle caps and concurrent-effect limits
- Reduced-flashing mode
- Independent screen-flash and camera-movement controls
- Respects Minecraft's Hide Lightning Flashes option

### Compatibility

- Fabric 1.21.1
- NeoForge 1.21.1
- Java 21
- No external shader pack required
- Defensive fallback under detected third-party rendering pipelines

### Installation model

- Client installation provides the complete visual and audio overhaul on any server.
- Installing on both client and server also enables configurable near-miss damage and ball lightning.
